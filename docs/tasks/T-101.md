## Goal
Build the Tauri 2 skeleton and everything the Phase 1 screens build on, so no screen brief edits a shared file: Cargo
workspace with stub commands, strict-TypeScript React UI (Vite, shadcn/ui, Motion Primitives), Harness tokens, app
shell, route registry with a placeholder per screen, provider strings file, the typed IPC contract + stateful mock
(`docs/tasks/T-101-ipc-contract.md`, part of this brief), and lint/test guards for rules 3, 5, 8, 9. Also land the
Tauri-only Makefile/CI/compliance edits ADR 0001 deferred to this scaffold.

## Design (in order; commit after each part so a re-dispatch can resume)
**Part A: toolchain, shared files, compliance plumbing**
1. Dependencies in one go: hand-write package.json; ask once for `pnpm install`, then once for
   `pnpm dlx shadcn@latest add <components> <4 Motion Primitives registry URLs>`. No other installs.
   Runtime: react, react-dom, react-router, @tanstack/react-query, @tauri-apps/api, @xterm/xterm, @xterm/addon-fit,
   motion, react-hook-form, zod, @hookform/resolvers, cmdk, sonner, lucide-react, class-variance-authority, clsx,
   tailwind-merge, tw-animate-css, @fontsource-variable/{inter,jetbrains-mono}, the @radix-ui/* the components need.
   Dev: typescript, vite, @vitejs/plugin-react, tailwindcss, @tailwindcss/vite, @tauri-apps/cli, vitest, jsdom,
   @testing-library/{react,user-event,jest-dom}, eslint, @eslint/js, typescript-eslint, eslint-plugin-{react,
   react-hooks,jsx-a11y,import-x}, eslint-import-resolver-typescript, globals, prettier, prettier-plugin-tailwindcss,
   ajv, ajv-formats, @types/{react,react-dom,node}. Banned (test-enforced): @tauri-apps/plugin-*, tauri-plugin-*,
   provider SDKs/CLIs, framer-motion, next-themes, HTML/markdown renderers, diff2html.
   shadcn (Tailwind v4, CSS vars): accordion alert alert-dialog badge button card checkbox command dialog dropdown-menu
   form input label popover progress radio-group scroll-area select separator sheet sidebar skeleton sonner switch
   table tabs textarea toggle tooltip. Motion Primitives → src/components/motion-primitives/: animated-group,
   text-shimmer, in-view, transition-panel. Scripts: dev, build (`tsc -b && vite build`), tauri, typecheck, lint
   (`eslint . --max-warnings 0`), test (`vitest run`), format, format:check. `packageManager: "pnpm@10.34.5"`,
   `engines.node: ">=24"`, `pnpm.onlyBuiltDependencies` (esbuild + whatever pnpm asks about).
2. Rust: `src-tauri/Cargo.toml` = workspace root (members crates/harness-core, crates/pty-view) + `app` package (lib
   `app_lib`; tauri 2, tauri-build 2, serde, serde_json, both crates; no plugins). `harness-core`: empty lib +
   `compliance::ceilings` consts (2 sessions, 30 prompts/h, 40 turns/task, 480 run-min/day, 30 idle-min, 5 s gap, 60 s
   backoff base, 3 limit errors, spend-cap max), a unit test per value; it never names pty-view, even in comments
   (the scan flags it). `pty-view`: empty lib (portable-pty comes later). `app`: the contract's stubs, listed in
   `generate_handler!` and build.rs `tauri_build::AppManifest::commands`. Root rust-toolchain.toml: 1.99.1 + rustfmt
   + clippy.
3. tauri.conf.json: productName "Harness", identifier "dev.local.harness"; window "main", title "Harness", 1280×800,
   min 1024×700, `dragDropEnabled: false`; `withGlobalTauri: false`; `security.freezePrototype: true`; devUrl
   `http://127.0.0.1:1420`; frontendDist `../dist`; no externalBin or resources. CSP: `default-src 'self'; script-src
   'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; font-src 'self'; connect-src ipc:
   http://ipc.localhost; object-src 'none'; base-uri 'none'; frame-src 'none'; form-action 'none'`; `devCsp` adds only
   what Vite HMR needs on 127.0.0.1:1420. capabilities/main.json: window "main", `core:default` + one
   `allow-<command>` per contract command, nothing else. Icons: neutral monogram via `pnpm tauri icon app-icon.svg`.
4. Vite: host "127.0.0.1", port 1420, strictPort (rule 5); alias `@` → src; vitest jsdom + src/test/setup.ts.
   tsconfig strict + noUncheckedIndexedAccess. .prettierignore: docs/, *.md, spike/, .claude/, compliance/,
   src-tauri/target, src-tauri/gen, dist, lockfile (the PostToolUse hook would otherwise reformat edited docs).
5. Makefile (Tauri only; drop the Swift branch and auto-detect; make 3.81, no .ONESHELL): prepend
   `/opt/homebrew/opt/rustup/bin` to PATH if it exists. `check-fast: compliance crate-boundary spike-test rust-fast
   ui-fast`; `check: check-fast compliance-selftest rust-full ui-full`. rust-fast = fmt --check, clippy --workspace
   --all-targets -D warnings, test --workspace --lib. ui-fast = pnpm typecheck, lint, test, format:check. rust-full =
   cargo test --workspace. ui-full = pnpm build, fail if `dist/` contains `__HARNESS_MOCK__`. spike-test = each
   spike/tests/*.sh via /bin/bash (skip if none). crate-boundary = scripts/ci/check-crate-boundary.sh: fails if
   `cargo tree -p harness-core -e normal,build,dev --prefix none` lists pty-view; `--tree-file F` for the self-test.
6. compliance/pty-boundary.conf: `PTY_SYMBOLS_RE='(pty_write|write_to_pty|PtyWriter|ptyWrite|writeToPty|pty_view|
   pty-view|pty-input)'` (one line), `PTY_DIRS_RE='(^|/)(scheduler|lead|orchestrator|harness-core)(/|\.)'` (covers
   harness-core incl. its Cargo.toml, and src/features/lead/). Selftest cases: harness-core Cargo.toml naming pty-view
   → dirty; src/features/lead/x.ts using ptyWrite → dirty; crates/pty-view/src/lib.rs defining PtyWriter → clean;
   check-crate-boundary.sh on saved trees with / without pty-view → fail / pass.
7. ci.yml: compliance job also shellchecks spike/ (`find spike -name '*.sh'`) and jq-validates tauri.conf.json and
   capabilities; stack job: dtolnay/rust-toolchain 1.99.1 (rustfmt, clippy), pnpm/action-setup@v4, setup-node 24
   (pnpm cache), `pnpm install --frozen-lockfile`, `make check`; Swift block removed. .gitignore: src-tauri/gen/,
   coverage/, *.tsbuildinfo, .eslintcache. CLAUDE.md "Still open" → one line: names are placeholders (rename before
   release, rule 8); Makefile/CI/pty-boundary.conf are Tauri-only since T-101.
