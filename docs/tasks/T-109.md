Status: proposed (awaiting ShivHax-YT; the hands-off approval of 2026-10-25, commit deb08f4, was revoked on 2026-10-26; only the human approves)

## Goal
Let the human pick the theme, tighten limits within the bounds from `get_limits`, set the summary budget, and manage API keys with required spend caps. Show the kill-switch state read-only (rule 12). A saved API key is never shown again: the backend keeps it in the Keychain and the contract never echoes it.

## Design pre-flight (before code)
- **Screen goal:** Set what you control, and see what the app cannot change.
- **Primary action (one per open tab, at least 44 px tall: `min-h-11`):** General: none (theme applies at once). Limits: "Save limits" when dirty and valid. API keys: "Save key and caps" when the key form is open. Kill switch: none.

## Behaviour
- **Limits:** bounds come from `get_limits`. `lower` allows [bound, ceiling]. `higher` allows [ceiling, bound]. An out-of-range value shows an inline error at once: "Looser than the built-in limit. Allowed: 1 to 2." A backend `rule_blocked` is shown the same way.
- **Caps (rule 11):** `daily_usd` and `weekly_usd` are required. Each must be finite, greater than 0, at most `spend_cap_max`, and weekly must be at least daily. There is no "no limit" option anywhere. Invalid input disables Save, and `set_api_key` and `update_spend_caps` are never called.
- **Key field:** `type="password"`, `autoComplete="off"`. Cleared on success. Never placed in query keys, toasts or logs. The toast says only "Key saved".
- **Gemini:** API key only. No sign-in control (rule 7).
- **Kill switch:** read-only. Show `source`, `fetched_at` and the signature state; `source` and any config text render with `UntrustedText` (mono for `source`), never as a link. `invalid_ignored` reads "Signed config didn't verify, so it was ignored." No toggle and no override.
- **Theme:** the radio uses the same theme state as the header (the hook T-101 exports; see Notes).
- **Copy:** provider names via `ProviderName`. Terms pages are named as plain text, with no links (the rule 5 test bans http(s) strings in `src/`).
- Do not auto-retry on `rule_blocked`.
