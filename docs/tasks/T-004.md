## Design
- `adapter-interface.md`:
  - Methods (language-neutral signatures): `start(task, worktree)`, `send(prompt)`, `events()`, `cancel()`,
    `authStatus()`, `capabilities()`, `usage()`, with errors and preconditions for each.
  - `capabilities().transport` is `headless | acp` only. There is **no** pty value (rule 3), and the registry rejects
    an adapter that declares neither.
  - Session state machine: `spawning → running ⇄ idle → exited | killed`, plus `rate_limited` (with backoff state),
    with every transition and its trigger event. Rule 10 timings referenced, not redefined.
  - `authStatus()` comes from each CLI's documented status command only (rule 4).
  - Mapping tables: raw Claude event → normalized, raw Codex event → normalized, plus an explicit "ignored" list.
- `event.schema.json` (JSON Schema 2020-12): `session_started{session_id}`, `message{role,text}`,
  `tool_call{id,name}`, `tool_result{id,is_error}`, `result{is_error, turns, tokens{input,output,cache_read?,
  cache_write?}, cost_usd?, cost_is_estimate}`, `rate_limited{reset_at?, retry_after_s?, raw_kind}`,
  `error{kind,message}`, `exited{code?,signal?}`, `unknown{raw_type}`. Every event also has `provider`, `ts`.
- `normalize/*.jq`: raw JSONL → normalized JSONL.

## Hard rules touched
| Rule | How | Test |
|---|---|---|
| 3 | Transport enum excludes pty; the interface has no method that writes to a terminal | test asserts the schema's transport enum is exactly `["headless","acp"]` |
| 4 | authStatus defined via documented status output only | doc review |
| 10 | `rate_limited` carries what backoff needs (reset time or retry-after when present) | test: the docs-sourced rate-limit fixture lines normalize to `rate_limited` |
| 1 | `result.tokens` and `usage()` feed the per-provider counters | test: every result event has numeric tokens |
