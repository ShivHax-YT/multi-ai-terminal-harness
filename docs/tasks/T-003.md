## Design
- `run.sh`: `spike_require_live`; scratch repo + worktree `codex-1`; then
  `codex exec --json --sandbox workspace-write -C <worktree> "<TASK>"`
  TASK: "Create a file named hello.txt whose only line is the three words hello from codex with no punctuation. Then reply DONE."
  Add a watchdog that kills the child's process group after 120 s. stdout → `captures/.../raw.jsonl`, stderr →
  `stderr.txt`. One invocation, no retries.
  **Banned flags**: `-c/--config`, `-p/--profile`, `--dangerously-*`, `--oss`, `--local-provider`, `--approve-for-me`.
  Use the default config and login only.
- `parse.jq`: outputs `{thread_id, event_counts: {"<type>": n}, items: {"<item type>": n}, commands_run: [..],
  final: {status, usage, last_message_excerpt (≤200 chars)}, limit_or_error_events: [...], unknown: [...]}`.
  Never fails on unknown types.
- `resume.sh <capture-dir>`: `spike_require_live`; reads `thread_id`; runs
  `codex exec resume <thread_id> --json "Append a second line to hello.txt that is only the word resumed with no punctuation. Reply DONE."` from the same
  worktree (check `codex exec resume --help` for where `--json` and `-C` go, and record it).
- `EVENTS.md`: same format as T-002's (observed vs from docs, redacted examples). Don't provoke rate limits.
- Fixtures: `sample.jsonl` from docs first; `observed.jsonl` (redacted) after the human's live run.
