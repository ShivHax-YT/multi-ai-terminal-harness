## Design
`spike/run-both.sh [--dry-run] [--keep]` (bash 3.2, `set -u`, `umask 077`):
1. Parse arguments (unknown argument: exit 2). `--dry-run` prints every command below with placeholder paths, plus
   `sleep 5` between the two runs, creates nothing, needs no `SPIKE_LIVE`, and exits 0. Nothing else runs before step 2.
2. Source `lib/common.sh`; `spike_require_live` at top level (exit 3 without `SPIKE_LIVE=1`). Install an INT/TERM/HUP
   trap that records the signal; once set, nothing new starts and the script exits 130/143/129 after cleanup.
3. `ROOT=spike/captures/run-both/<UTC stamp>` (gitignored, fresh, refused if it exists). Run `spike/preflight.sh` once
   with output to `$ROOT/preflight.txt` (versions, signature, sign-in; no prompt). Non-zero exit: stop, exit 1.
4. `SPIKE_CAPTURES_ROOT=$ROOT spike/claude/run.sh` once; record its exit status. Then `sleep "$GAP_SECS"` with
   `GAP_SECS=5` (rule 10, applied across providers as the human asked). Then `SPIKE_CAPTURES_ROOT=$ROOT
   spike/codex/run.sh` once. Codex still runs after a Claude FAIL (different provider, one prompt), never after a signal.
   `SPIKE_CAPTURES_ROOT` is read by `spike_capture_dir` only; the runner rebuilds the CLI child's environment.
5. Find exactly one capture dir per CLI under `$ROOT/<cli>/` (0 or more than 1: FAIL for that CLI). Normalize
   `raw.jsonl` with T-004's jq into `$ROOT/<cli>.normalized.jsonl` (written with `noclobber`).
6. Read the worktree path from `worktree.path` (claude) or `worktree.txt` (codex) only after `safe_input` (regular file,
   not a symlink, one link, `spike_under_cli_home` false) and only if it lies under `spike_root` with no control
   characters. Check `hello.txt` byte-exact against `CLAUDE_HELLO` / `CODEX_HELLO` (constants equal to the text inside
   each merged run.sh's `TASK`; a test enforces it). List changed files with `git -C <wt> status --porcelain`.
7. One row per CLI: provider, run.sh exit, session/thread id (first 4 characters + `...`), turns, tokens in/out/
   cache_read/cache_write, estimated cost, counts of warning, rate_limited and unknown, changed files, hello ok, PASS
   or FAIL. **PASS** = run.sh exit 0, exactly one `session_started`, exactly one `result` with `is_error` false and
   numeric tokens, 0 `rate_limited`, hello.txt exact. `unknown` > 0 does not fail; it prints "needs mapping (T-004)".
   The same rows go to `$ROOT/run-both.json`. All printed text is filtered to printable characters.
8. Unless `--keep`, `spike_cleanup` each scratch run dir (`${WT%/repo-wt/*}`). Captures always stay for the
   human's redaction step. Exit 0 only if both PASS, else 1.

`spike/PHASE0-REPORT.md` (template; pre-filled facts marked "known 2026-10-26, confirm"): date, macOS and bash
versions, commit; per CLI: version, install method, signature and team id, sign-in check; run-both rows; event types
seen vs EVENTS.md (observed / from docs / new); rate-limit shapes observed vs docs (routine `rate_limit_event` on a
normal run; Codex item errors as warnings; none provoked); resume results from T-002/T-003; stderr notes (Codex stdin
line); surprises (npm vs native install, ambiguous Codex task); implications for T-004 and T-120..T-122; ADR 0001
impact; the Phase 0 done-when checklist (run-both PASS for both, `make compliance-selftest`, `make check` on macOS,
redacted `observed.jsonl` per CLI committed with `test_normalize.sh` green); follow-ups; human sign-off line.
