# T-007: Phase 0 end-to-end run and report

Status: approved by ShivHax-YT on 2026-10-25

## Goal
One human-triggered script that meets the Phase 0 "done when" from docs/BUILD_PLAN.md: both CLIs finish a scripted
task in their own worktrees and return parsed, normalized results. Plus a report template that records what Phase 0
learned for Phase 1.

## Owned files (exclusive)
- spike/run-both.sh
- spike/PHASE0-REPORT.md

## May read
- Everything under spike/ and docs/spec/, docs/BUILD_PLAN.md, docs/HARD_RULES.md, docs/adr/0001-stack.md

## Must not touch
- All other spike/ files (report needed changes to the lead), Makefile, CI

## Design
- `run-both.sh [--dry-run] [--keep]`:
  1. `spike_require_live` (skipped for `--dry-run`); run `spike/preflight.sh` and stop if either CLI isn't signed in.
  2. One scratch repo, two worktrees (`claude-1`, `codex-1`).
  3. Run T-002's Claude task, wait **at least 5 s** (rule 10), then run T-003's Codex task. Sequential, never
     parallel (rule 1 concurrency is not exercised here).
  4. Normalize both captures with T-004's jq, then print one table: provider, session/thread id (redacted), turns,
     tokens in/out, `git diff --stat` per worktree, PASS/FAIL (PASS = hello.txt exact content and a non-error
     `result`).
  5. Clean up unless `--keep`. Exit non-zero if either FAILs.
  `--dry-run` prints the exact commands it would run and makes no CLI call.
- Each run script is called the way T-002 and T-003 define. If a needed hook (for example an option to pass in an
  existing worktree) is missing, report it to the lead rather than editing those files.
- `PHASE0-REPORT.md` (template, filled in after the human's live run): date, CLI versions + signature results, PASS/FAIL
  per CLI, event types seen, rate-limit shapes (observed vs docs), resume behavior, surprises, implications for the
  adapter interface, anything that affects ADR 0001, and the Phase 0 done-when checklist.
