# T-006: Worker HANDOFF format and parser

Status: approved by ShivHax-YT on 2026-10-25
Phase: 0   Model hint: sonnet
Depends on: none   Runs: parallel (wave 1, with T-001 and T-005)

## Goal
Define the fixed HANDOFF.md format that harness workers write when they finish (docs/ARCHITECTURE.md "Dispatch" and
"Collect"), based on the AGENTS.md format, and a parser that turns it into JSON while treating every byte as
untrusted data.

## Owned files (exclusive)
- docs/spec/handoff.md
- spike/handoff/parse.sh
- spike/fixtures/handoff/ (all files)
- spike/tests/test_handoff.sh

## May read
- AGENTS.md (HANDOFF.md format), docs/ARCHITECTURE.md (Security section), docs/HARD_RULES.md

## Must not touch
- spike/lib/*, AGENTS.md, anything outside the owned list, Makefile, CI

## Design
- Format: the AGENTS.md sections in order (`# HANDOFF T-###`, Summary, Files changed, Tests run, Hard rules touched,
  Open risks / questions, Confidence). `handoff.md` specifies each section's allowed content, size caps (for example
  Summary ≤ 5 lines, whole file ≤ 16 KB), and that Confidence starts with `low`, `medium` or `high`.
- `parse.sh <file>` → JSON on stdout:
  `{task_id, summary, files_changed: [{path, note}], tests_run, hard_rules: [..], risks, confidence: {level, why}}`.
  Exits non-zero with a clear message on a missing, duplicated or out-of-order section, a bad confidence level, or an
  over-size file.
- Untrusted input: the parser never `eval`s, `source`s or expands content. Text goes into JSON strings via
  `jq --arg`/`--rawfile`, never through shell interpolation into a command.
- Fixtures: `good.md`, `missing-section.md`, `bad-confidence.md`, `oversize.md` (generated by the test, not committed
  if large), and `injection.md` containing instruction-like text plus `$(touch <marker>)` and backtick payloads.

## Notes / open questions
- **Lead amendment (round 7, confirmed under the hands-off authorization 2026-10-25):** after six gate rounds the interface became
  `parse.sh --root <worktree>` (reads exactly `<root>/HANDOFF.md`) and the parser is one perl process using core
  JSON::PP instead of `jq --arg`, so no content is ever reopened by path. The intent (no shell interpolation of content)
  is kept and strengthened. Threat model and caller precondition: docs/spec/handoff.md.
- This is the format for the **app's** workers. It mirrors this repo's own AGENTS.md HANDOFF format on purpose, so
  the same parser can read this repo's handoffs too.
