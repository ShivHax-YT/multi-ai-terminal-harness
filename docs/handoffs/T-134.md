## Open risks / questions

- Original seven-finding report: missing. Not claimed as resolved.
- Finding 1, IME/dead-key drop: fixed in the gate. Not confirmed with a real IME in WebKit.
- Finding 2, stale pid on Stop: fixed. Stop holds the unreaped child lock and signals with `TIOCSIG` on that pty master. After the wait, stop returns `AlreadyExited` and does not signal. A failed signal returns an error and leaves the session running. Idempotent once the child is gone.
- Finding 3, slot released early: fixed. `stopping` counts as live. A failed stop stays `running`. Restart after Stop waits for the exit callback.
- Finding 4, quit does not wait: fixed for the hook. `RunEvent::Exit` calls `shutdown()`, which signals and waits up to 2 seconds for the exit callback. A process that ignores SIGHUP can still be alive when that wait ends. There is no pid `SIGKILL`.
- Finding 5, Stop dialog follows the screen: fixed. `SessionDetail` is keyed by `sessionId`, and `stopping` clears when the id changes.
- Finding 6, stale attach snapshot: fixed with an attach generation. A slower `attach()` does not `reset` the view.
- Finding 7, query replies: fixed. Cursor-position and device-attribute replies are dropped before the turn check. The write queue re-checks take-over and does not flash a refusal for a chunk already queued.
- Finding 8, unreviewed release has no task blocker: fixed. `release_unreviewed` is pushed when `release_reviewed` is false. `usable.lead` and `usable.worker` are set false there. No worker is started.
- Grok human terminal: unavailable. `compliance/vendor-pins.toml` has no grok pin. Team id, signing identifier, and reviewed hash were not invented or copied from a local install.
- Kimi human terminal: unavailable, same reason.
- Gemini human terminal: unavailable. The tree has no documented API-key flag or environment variable, and `set_api_key` is unimplemented. An empty-argv `gemini` session would not satisfy rule 7. `start_terminal("gemini")` stays refused. No Google sign-in.
- GLM human terminal: unavailable. `glm` is not an allowed executable name. A GLM session would be the pinned `claude` binary plus a Z.ai base URL. This repo does not name that variable, so none was added. `CLAUDE_CONFIG_DIR` was not set.
- No headless or ACP argv was added (`grok -p`, `grok agent stdio`, `kimi acp`, `gemini -p`, `gemini --acp`).
- Automated workers, worktree execution, and unreviewed-release automation stay off for every provider, including Claude and Codex.
- Wrapped scrollback now prefixes the current private modes (bracketed paste, mouse, alternate screen) so a reattached xterm is less likely to lose them. That is extra to the eight findings. It is not a full terminal-mode emulator.
- Quit's 2 second cap is the remaining lifecycle limit.
