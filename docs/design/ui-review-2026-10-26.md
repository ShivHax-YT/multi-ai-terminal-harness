## Gaps in what T-101 built (lead-owned files; fix before wave 1 unless noted)

1. **Stagger total unbounded.** `Stagger` = 220 ms item + 40 ms step, so n items take 220 + 40(n-1) ms (5 chips 380 ms,
   10 rows 580 ms). `motion.test.tsx` checks only the per-item value. Fix: cap the total at 300 ms (shrink the step or
   stagger only the first items) and test the total. (`src/components/motion/index.tsx`)
2. **Ctrl vs ⌘.** `shell.tsx` accepts `metaKey || ctrlKey` on every platform for K and 1-7, and shadcn `sidebar.tsx`
   binds Ctrl/⌘+B. In terminal take-over these swallow Ctrl+K (kill line), Ctrl+B (tmux prefix) and Ctrl+digit.
   `modKeyLabel` says "both modifiers work". Fix: ⌘ only on macOS, Ctrl elsewhere; ignore keys whose target is inside
   the terminal while take-over is on. Before T-106.
3. **Focus rings below 3:1.** shadcn controls use `outline-none` + `ring-[3px] ring-ring/50`, which overrides the
   global 2 px solid `--ring` outline. 50 % orchid over the background is about 2.5:1 (light) and 2.9:1 (dark).
   `tokens.test.ts` checks only the solid token. Fix: solid `--ring`, 2 px, offset 2 px on every control; test it.
4. **Reduced motion covers only the wrappers.** Dialog, AlertDialog, Popover, Select, DropdownMenu, Tooltip, Sheet
   (tw-animate-css) and the sidebar keep animating under Reduce Motion. Fix: one global
   `@media (prefers-reduced-motion: reduce)` rule in `globals.css` that zeroes animation and transition durations.
5. **Layout animation.** The sidebar collapse transitions `width`, `left`, `right` (200 ms linear). Fix: instant, or
   a documented exception.
6. **Errors not instant.** Input/Textarea/Select use `transition-[color,box-shadow]` and Button `transition-all`, so
   the `aria-invalid` ring fades in (about 150 ms). Fix: drop box-shadow from those transitions.
7. **No 44 px size.** Button sizes stop at `h-10` (40 px); the README does not state the 44 px rule. Briefs use
   `min-h-11` until the lead adds a size.
8. **Looping indicator.** The Shimmer fallback is a 1.6 s infinite opacity pulse; the README has no rule for looping
   status indicators. Text Shimmer itself is a gradient (rejected list) plus background-position.
9. **One H1.** The shell header renders the only `h1` (nav label). Screens use `h2`; T-110 checks exactly one `h1`.
10. **README.** Its pre-flight list has 6 items; add the inspiration technique, the 44 px rule, about 65ch, the front
    door model, and items 4 and 8 above.
